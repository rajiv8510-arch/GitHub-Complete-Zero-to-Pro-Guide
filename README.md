## ⚡ Quick Start

**New PC Setup (60 minutes):**

1. **Install Software:**
   - [Git](https://git-scm.com/download/windows)
   - [Arduino IDE 2.x](https://www.arduino.cc/en/software)
   - [VS Code](https://code.visualstudio.com/)

2. **Configure:**
```cmd
   git config --global user.name "Rajiv Yadav"
   git config --global user.email "your.email@example.com"
```

3. **Clone Libraries:**
```cmd
   cd /d F:\ArduinoWorkspace\libraries
   git clone https://github.com/rajiv8510-arch/Arduino-Library-RajivButton.git RajivButton
```

4. **[Read Full Setup Guide →](COMPLETE-GUIDE.md#initial-setup)**

## 🎯 Common Tasks

### Pull Latest Changes
```cmd
cd /d F:\ArduinoWorkspace\libraries\RajivButton
git pull origin main
```

### Commit and Push
```cmd
git add .
git commit -m "Your descriptive message"
git push origin main
```

### Clone New Library
```cmd
cd /d F:\ArduinoWorkspace\libraries
git clone https://github.com/rajiv8510-arch/Arduino-Library-NewLib.git NewLib
```
